
# Research Data

This directory contains the datasets associated with the 5G printed antenna research project.

## Organization

- `raw/`: Original data extracted from CST Studio Suite simulations.
- `processed/`: Cleaned and prepared datasets for Python and Machine Learning.

## Data Parameters

Input features:
- Wp: Patch width
- Lp: Patch length
- Hs: Substrate thickness

Output parameters:
- S11: Reflection coefficient
- Gain: Antenna gain

## Formats

CSV, TXT and other appropriate scientific data formats.
