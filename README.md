
# 5G Printed Antenna Design and Optimization

## Research Project

This repository is dedicated to the design, simulation, analysis, and optimization of printed antennas for 5G applications.

The project explores the integration of electromagnetic simulation, Python programming, Machine Learning, and multi-objective optimization techniques.

## Research Objectives

The main objectives are:

- Design and model printed antennas for 5G applications.
- Analyze electromagnetic performance using CST Studio Suite.
- Evaluate the reflection coefficient (S11) and antenna gain.
- Develop Python-based tools for data processing and analysis.
- Apply Machine Learning techniques to antenna performance prediction.
- Investigate MOZO (Multi-Objective Zebra Optimization) for antenna optimization.

## Research Methodology

The proposed workflow includes:

1. Antenna design and electromagnetic simulation using CST Studio Suite.
2. Extraction and organization of simulation results.
3. Dataset preparation using Python.
4. Machine Learning model development and evaluation.
5. Multi-objective optimization using MOZO.
6. Performance analysis based on S11 and antenna gain.
